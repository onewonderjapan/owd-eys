# EYS 公开试玩

用户授权：与 owd-pet-content-studio 相同方式公开，A 记录为 eys；进入网页先选择角色，再进入小镇。源码组织私有；网页与必要运行资产公开。保持二创、技术验证、娱乐、非商用声明。

从当前已验证地图 map_reference_v2 与衣橱 4.3.27 派生。27 个角色、65 件装备；GLB 与头像采用内容哈希文件名，存于 S3，不进入 Git。原始 Blender 文件与内部制作记录继续保留在 W2。

入口视觉：沿用鹅教堂石板青灰 #293c3f、木色 #c9a77c、暖窗 #ffe0a0、浅羽色 #f2f1e9、淡紫 #a5a0be。标题用 Georgia / 游明朝与小镇插画配合；操作与角色名使用系统黑体。27 张真实角色缩略图构成角色册，左侧展示选中角色，右侧滚动选择，手机先展示选择控件再进入画面。

页面初始只加载头像和角色清单；确认进入才加载地图和所选装备。换角色保留地图；销毁替换角色资源。键盘、手机和房间碰撞复用已验证模拟。

验收：发布包依赖完整且不含源文件/私人路径；桌面与手机角色选择、至少两个不同角色进入、换角色、真实按键移动、房间入口、声明；HTTPS、S3 私有回源、A 记录和 Git 私有属性。
