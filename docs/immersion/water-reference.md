## 施工采用的关键关系

| 元素 | 实现要求 |
| --- | --- |
| 目标鹅 | 使用投票目标原有 preset，保持服装；不把参考图里的那套服装套给所有角色 |
| 链条 | 鹅下方连到石块上方，悬垂段约为目标可见身高的 1.2–1.5 倍；这是从构图估计的设计比例，不是官方尺寸 |
| 石块 | 深灰不规则低多边形石块，初始宽度约为目标可见宽度的 0.5–0.7 倍，允许为可读性微调；处于目标下方 |
| 背景 | 深海军蓝渐变、弱上方散射光、克制雾感；不用亮青色游泳池、可见海床或密集粒子取代 |
| 运动 | 鹅、链、石整体缓慢下沉，石块始终低于鹅，链端持续连通；轻微摆动是改编，不作官方动作还原声明 |
| 水下关键画面 | 6 秒段落的 2.2–5.6 秒作为重点，至少约 3 秒可以读清关系，最后 0.4 秒淡出 |

链节使用Blender道具包中prop_chain_link的低面数几何与材质，运行时通过InstancedMesh生成约24–32节交替转向；沿上下端点插值布置，半径与段距调到视觉连贯。资源只创建一次，每帧仅更新实例矩阵；不引入绳索物理或每帧新建网格。石块单独网格，链的下端锚点绑定石块顶部，上端绑定目标下身前侧，被衣服遮住的实际结点无需杜撰复杂绑法。

**自己出局的 POV：** 相机随自己的眼位下沉，保持可环顾；低头能看到下方长链和石块，抬头看到较亮水域。水下 pitch 可扩到约 -1.45 至 1.10 rad，默认轻微向下；进入时柔和调整，减少动态模式不强制转头。自己的头与脸不遮挡镜头，屏幕下缘翅膀与链条提供身体联系。无需为了展示整只鹅强切自己到第三人称。

**NPC 出局的观演镜头：** 入水前保留岸边眼高；水下阶段短淡切到固定平视镜头，展示完整目标鹅＋长链＋石块，构图以本图为准。这是观演转场，不把它描述为陪同鹅也潜入水底。可以有极轻微横向观察，不能改成俯视以致链石叠在鹅身上。

码头、投下、水花、稀疏气泡与上方光变化是衔接现有地图的项目改编。气泡为可选辅助，最多 8 个且不遮链；水面只需在入水过渡时表达，不必在核心构图中一直可见。
