# POV 会议与出局体验设计

版本：设计 1.2（2026-09-14，用户沉水参考＋Blender道具流程）。状态：可交给 ZCode（GLM-Flash）施工；以下时长和尺寸是设计目标，尚非运行实测。沉水细节见 [water-reference.md](water-reference.md)。

## 1. 范围与体验目标

让玩家感觉自己是一只鹅：翅膀碰响铃铛，坐在桌边看其他角色发言，被选中时从自己的眼睛看到水面远去或火光迎面而来。仍使用现有鹅教堂地图；圆桌与出局是短暂演出空间，不加入地图选择、探索区域或新地图资产。

| 纳入这一轮 | 暂不纳入 |
| --- | --- |
| 法院铃、提示、按铃动作与声音 | 完整地图重建、增加地图 |
| 8 席圆桌：玩家＋7 位现有角色 NPC | 联机、语音聊天、AI 对话、身份技能系统 |
| 3 轮短发言、选择对象、示意投票与结果 | 原作完整胜负规则、真人投票、公平性算法 |
| 沉水、火堆；自己出局或旁观 NPC 出局 | 太空出局、仓库火灾机关、额外死亡方式 |
| 跳过、重播、静音、低动态效果、失败重试 | 新后端、账户、统计上报、付费素材/生成调用 |

HUD 使用简短的「体验模式 · NPC 演出」，避免把脚本 NPC 展示为联网玩家。原有非官方、非商业提示继续可见。

## 3. 从漫游到会议

### 法院里的铃

- 保留现有地图所有物体和 landmark，不移动旧 `meeting` 标记。新增一座小铃台，放法院东南内侧，金色钟罩、可见钟舌、深木台座。禁止用浮动按钮代替铃的模型。
- 首版坐标：铃台基座 `(x,y,z)=(9.70,0.338,-7.65)`；玩家交互站位参考 `(9.12,-7.56)`，来自原图像素 `(678,153)`。这些地面点已在当前导航模型中确认无碰撞且属于法院 04；尚需施工后的视觉检查。
- 铃台占地半径 0.16，总高约 0.80；把占地代理加入运行时导航副本，不写回原地图碰撞 JSON。判定范围距铃台水平距离 ≤0.95、玩家在 room 04、无暂停/帮助弹窗。
- 进入范围显示「E 按铃开会」和触摸按钮「按铃」。E 优先按铃，离开范围恢复原有 E 查看；不隔墙响铃、不自动触发。铃铛可点区域只作补充，E/触摸按钮是可靠入口。
- 首次触发先准备 8 个独立演出角色，显示 `正在准备会议 3/8`。玩家尚在原地图，移动冻结，随时可取消；资源全就绪后才播放按铃。
- 1.2 秒按铃：0–0.3 秒右翅伸到铃前；0.3 秒钟舌敲击、清脆声音；0.3–0.9 秒钟罩余摆与翅膀收回；0.9–1.2 秒短淡出。铃声是用户点击后启动的本地 Web Audio 合成，不强依赖声音成功。
- 无论原先俯视还是 POV，按铃期间切换到鹅的眼高。镜头朝铃，不瞬间钻入铃体；先保存原视角，完整退出后恢复。

### 圆桌与座位

- 独立的临时会议 Scene，继续使用同一个 WebGLRenderer。没有入口走廊、探索碰撞或地图列表；进入即在自己的座位。
- 深木圆桌＋8 把有靠背的木椅；暗红桌面细节和局部法院风格墙板。暖色顶光照亮角色脸，冷色窗光提供轮廓。地面与背景保持克制，不能用纯黑背景掩盖欠缺的构图。
- 地面 y=0；桌半径 1.10，桌面 y=0.72、厚 0.09；座位中心半径 1.62，椅面 y=0.30。座位 `i` 的角度 `i*2π/8`，位置 `[sin(angle)*1.62,0,cos(angle)*1.62]`，面向桌心；玩家固定 0 席。相机初始 `[0,1.05,1.62]` 朝桌心 y=0.85，FOV 78。尺寸允许在 ±15% 内为服装避穿模调整，必须整体保持圆桌与眼高关系。
- 玩家＋7 NPC 使用真实 actor preset。NPC 顺序从候选 `cast.02, cast.03, cast.04, cast.05, cast.07, cast.08, cast.09, cast.10` 中排除玩家后取前 7，角色号不是虚构用户名。玩家穿戴和颜色不变。
- **坐在椅上围桌，不站在桌上。** 沿用静态鹅体，给演出副本加坐姿包装组：身体落在椅面，双脚前伸下垂，翅膀靠桌沿或身体侧面。座位留出帽子/武器空间，角色服装不得删减。
- 当前基础 GLB 有 `BASE | Foot | shin`、`webbed paddle`、`toe seam` 与 `BASE | rounded wing` 网格，未确认骨骼动画。按名字前缀和局部位置识别部件，不硬编码 `.080` 等导出尾号。对副本保存局部变换后做简单 pivot 姿态；保留脚缝与对应脚一起移动。若某件衣服穿模，调椅距/身体姿态，不能重建成廉价通用鹅。
- 玩家看不到自己整颗头。会议自己的整身演出模型隐藏，仅在画面下缘显示从玩家演出副本提取、独立变换的左右翅；俯看能读出自己也在桌边。提取视图与原副本共享只读资源时只由角色所有者统一释放，不能双重 dispose。
- 从进入会议到退场始终有其他角色可见。发言时小幅转向、2–4° 身体倾斜及翅膀抬落；轮到听众则看发言者。不用大幅全身上下抖动代替说话。

## 4. 发言、投票与结果

1. `seating` 0.8 秒：短淡入到已坐好的眼高，椅子轻响，其他鹅看向玩家。低动态模式不做下沉或身体摆动。
2. `discussion` 共 3 段，各 2.6 秒：由 NPC 1/2/3 顺序说「我刚才在码头。」「先听听大家怎么说。」「那我们投票吧。」字幕位于桌沿下方；发言者有暖色轮廓/小标记。可按「开始投票」提前进入投票。
3. `voting` 无强制倒计时：底部显示 7 位 NPC 的头像和原有标签；默认未选。点头像只选择，再按「确认投票」提交。另设明确按钮「体验自己被投出」，同样确认后开始结果；这是演出入口，不能暗中修改普通投票结果。
4. 本轮不声称模拟公平投票：普通选择中玩家和 NPC1/2/3 的票投向选定目标，NPC4/5/6 投向下一个不同 NPC，NPC7 弃票，合计 8 票，目标 4 票胜出；自己的演示入口则 7 NPC 投玩家，玩家弃票。只展示这套确定性的演出票数，并保留「NPC 演出」标记。
5. `result` 1.2 秒：目标角色被暖光点亮，其他鹅依次看向目标，显示「〈角色标签〉被投出」。禁用重复确认。
6. 会议右上角的「出局演出」选择「沉水（默认）／火堆（改编）」；在 discussion/voting 可改，提交后锁定。这是演出选择，不冒充地图选择。未来地图差异由配置 `mapId -> defaultEjection` 扩展；当前只登记真实 `map_reference_v2 -> water`，不填未核实地图。

PC 与手机均支持拖动画面环顾。会议保持坐定，不开自由走动；yaw 自由、pitch 限制约 -0.70 至 0.55 rad。会议不自动重新锁定鼠标；拖动操作即可，按钮点击不会触发转头。

## 5. 两种出局短画面

共同原则：只做足够被看见的局部布景。自己的 POV 与 NPC 旁观由同一目标角色、同一时间线决定；不能将不同的鹅替成目标。全程可「跳过」，无血腥、损伤模型或持续尖叫。

| 时间 | 沉水，约 6 秒 | 火堆，约 5 秒 |
| --- | --- | --- |
| 0–1.2 秒 | 短木栈桥、连着石块的链条、前方水面；两位陪同鹅在侧后方。这段是项目衔接设计 | 木地面、两位陪同鹅、前方石圈火坑。目标以轻微离地的抬起姿态进入火光 |
| 1.2–2.2 秒 | 目标向水面外移并下落，水花遮住画面约 0.15 秒；相机随后进入水下 | 目标被抬向火坑；自己的镜头看见两侧翅膀与前方火焰，轻微侧倾 ≤4° |
| 水：2.2–5.6 秒；火：2.2–4.8 秒 | 深蓝水下，鹅在上、长链与下方石块构成完整关系，缓慢下沉；旁观平视构图对照用户图，自身 POV 低头可看链石 | 目标被投到石圈以内，短弧线位移；自身 POV 最后接近火光；旁观视角明确看见目标落入火坑 |
| 结束 | 最后0.4秒淡黑，显示「本次演出结束」；保留上明下暗的水域方向，不新增触底动作 | 暖色火焰遮挡后淡黑，显示「本次演出结束」；不留站在火旁的假出局画面 |

沉水布景以现有小镇木码头、海水颜色为依据，只搭约 6×6 的舞台；火坑约 4×4，木柴、石圈、少量火焰片与暖光，不做大型城镇街景。七类实体道具在S1用Blender制作，保留可编辑.blend并导出GLB；Three.js负责摆放、实例、灯光、镜头、水/火动态效果和交互。具体资产、官方skill入口、导出与接入要求见 [blender-assets-plan.md](blender-assets-plan.md)。

自己的相机随目标眼位，水下可低头看链条与石块；NPC沉水在入水后淡切固定水下平视观演镜头，完整呈现参考图的鹅/链/石上下关系，不声称陪同者同时潜水。火堆旁观仍固定陪同者眼高。均不强行切全知俯视镜头。链条用低面数链节实例、石块用独立网格，上下锚点保持连接，无需真实链条或刚体物理。水下以深蓝留白为主，水面与稀疏气泡只作过渡/辅助；火焰使用少量几何片/粒子和透明度变化，不新增后处理依赖。

结束卡提供「重播本段」和「返回小镇」。重播使用已提交目标及演出类型，重新计时；返回淡入恢复铃前原位置、朝向及原俯视/POV模式。不会真的删除角色、扣除生命或把玩家传进水里。另可显示「再开一场」按钮，但通过返回漫游后再次按铃实现，不创建第二个会话。

## 6. 输入、舒适度与异常

- 演出期间隐藏方向盘、位置查看、回出生点和视角切换，HUD 保留「退出会议」、静音与跳过。代码层也拦截 WASD/E/V/home，不能只藏按钮。全局「更换角色」先清理会话，再返回角色册。
- Esc：漫游仍按已有规则先释放鼠标锁；演出在未锁定鼠标时直接取消并返回原位置。取消任何阶段都只恢复一次，不能触发两次 stop。键盘焦点回到游戏画面；取消时清空 keys/touches/pointer capture。
- 切后台/失焦暂停时序和音频；回来不快进。WebGL context loss 复用现有暂停提示，恢复后同一阶段继续；手动退出始终可用。
- `prefers-reduced-motion` 或设置「减少动态」时去掉头晃、倾斜、强制转头/坠落移动，使用固定 POV 关键画面＋短交叉淡入；保留水下/火坑的结果辨识。字幕全程可读，不靠音频传递必要信息。
- 默认声音开，用户手势成功解锁后才播放。静音与低动态开关仅保存浏览器本地偏好，不联网。拒绝音频、localStorage 不可用都不阻止体验。
- 资源失败：不进入空会议；在原地图显示「会议准备失败，可重试」和「重试／返回漫游」。晚到的加载结果不能拉回已退出的会议。再次按铃只重试失败部分或干净重建本会话，不复用 rejected Promise。
- 桌面目标 1440×960，移动目标 390×844、844×390。按钮触区 ≥44 px，字幕不能覆盖鹅的脸；底部头像条可横滚，但页面本身不能横向溢出。使用 safe-area inset。
- 不承诺未经实测的帧率。继续使用 DPR≤1.35；会议 8 个角色、陪同最多 2 个（从 8 个中复用），单舞台只渲染一个 Scene。火焰 ≤24、气泡 ≤8；链节约24–32个，使用实例绘制。不每帧创建几何/材质，不累积定时器/场景/音频节点。
