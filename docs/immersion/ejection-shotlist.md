## 候选镜头(按建议优先级)

### E1 · 星空弹射(SS Mothergoose 气闸)⭐ 推荐首个

- **参考**:`immersion_20260913` 官方 Steam 截图(鹅飘出气闸、星空、会议名册浮层),视觉已确认
- **我们的改编**:不做飞船——改编为**钟楼顶被抛向夜空**:抛出后镜头仰角翻上,星空穹顶、
  小镇缩成脚下灯光,鹅缓缓飘远。官方图只证明"太空飘移"画面存在,触发为本项目改编
- **复用**:现有抛物线轨迹 + dome(改星空贴色)+ 相机 track——**全场最省,几乎零新资产**
- **工作量**:S。新事件:入夜空后星星闪烁、飘移旋转

### E2 · 流沙吞没(Ancient Sands)⭐ 复用之王

- **参考**:`mummy_*.jpg`、`locusts_result.jpg`(Ancient Sands 官方帧;沙暴为该图官方危害)
- **我们的改编**:广场出现流沙坑,被投者站入后缓缓下沉——**本质是沉水的沙色变体**,
  直接复用水下渲染/链石可换"古棺沉入";POV 结尾黄沙没顶
- **工作量**:S(水舞台复制改色+坑体模型一个)

### E3 · 吊灯砸落(Mallard Manor)

- **参考**:`chandelier_sabotage.jpg`(启用)、`chandelier_crush.jpg`(砸落结果,官方帧含血渍——
  我们保持非血腥,用羽毛/花瓣替代)
- **我们的改编**:法院/教堂吊灯摇晃三下 → 砸向被投者。POV:被投者站在灯下看灯晃近 →
  黑屏;旁观者看吊灯坠落全程
- **工作量**:M。新资产:吊灯模型(S1 可建);坠落+压扁时间轴;第一个"从上往下砸"类
- **复用**:处决弧线改为"灯从上方来",人群散开逻辑复用

### E4 · 巨石滚落(Jungle Temple)

- **参考**:`boulder_path.jpg`、`boulder_crush.jpg`(官方帧)
- **我们的改编**:巨石从长街一端滚来,被投者被碾过(非血腥:被压成"纸片鹅"再弹起飘走,
  喜剧化处理)。POV:迎面滚来→白闪
- **工作量**:M。新资产:巨石模型;滚动+方向;人群躲闪动画(现有 walk 避让可凑合)

### E5 · 断桥坠落(Jungle Temple)

- **参考**:`bridge_sabotage.jpg`、`bridge_drop.jpg`(官方帧)
- **我们的改编**:码头/桥板断开,被投者随桥板坠落(我们已有码头+水面!坠落终点接现有
  水下场景,等于"沉水"的加长前奏版)
- **工作量**:M。桥板资产+断裂下坠;后半段完全复用沉水
- **注意**:与 E2/E4 相比差异化一般,放中后

### E6 · 冲水飞湖(Mallard Manor)

- **参考**:`toilet_task.jpg`、`toilet_lake.jpg`(官方帧:通马桶任务+落水湖)
- **我们的改编**:喜剧向——被投者被"冲"出去旋转飞过小镇落水(官方也是这个搞笑味),
  旋转+抛物线+落水接现有水下
- **工作量**:M。旋转相机+啸叫音效;落水复用
- **定位**:彩蛋镜头,风格最跳,放最后

### E7 · 监狱平票(Goosechapel 官方机制,非死亡)

- **参考**:官方 v1.03 补丁说明(平票入狱、两把钥匙、牢房自动开)
- **我们的改编**:平票时被投者被押入现有警察局牢房场景(短 POV:牢门关上),一局后自动放出
- **工作量**:M-L。涉及局外状态(关押期间不能被"演出处决"),规则改动比纯演出大
- **定位**:规则型功能,单独规划,不塞进演出池

### E8 · 会议尸体掉落小动画(v4.01 官方机制)

- **参考**:官方补丁说明(会议中死亡者有 body-drop 动画并留在名册上)
- **我们的改编**:会议名册上被投出/已死亡的角色卡片加一个倒下小动画
- **工作量**:S(纯 UI/CSS)。适合作为任意镜头的甜点

## 建议路线

```
E1 星空(S) → E2 流沙(S) → E3 吊灯(M) → E4 巨石(M) → E5 断桥(M) → E6 冲水(M) → E7 监狱(单独)
                    (E8 会议名册小动画可随时插入)
```

理由:E1/E2 几乎零新资产、复用现有穹顶与水下管线,先把"每局出局演出不重样"立起来;
E3/E4 引入"从上方/正面来的死亡"新机制;E5/E6 是已有场景的变体收尾。

## 统一边界(每个镜头开工前重读)

- 官方截图仅作参考对照,**不进入 src/ 与生产资产**;参考原图存放于 reference_research
- 非血腥:官方帧里的血渍一律改为羽毛/花瓣/布条
- 每个镜头开工前写一页 design(纳入/暂不纳入 + 参考边界表),走现有 smoke/publish 门
- 尊重 reduced-motion(坠落/旋转类必须可关)与手机触控

## 每镜头技术清单模板(复用 1.2.0 沉水的结构)

- `immersion-ejection.js` 新增 stage 分支:场景/灯光/资产 + 节拍表(beats)+ 自/NPC 相机轨道
- 相机轨道 = 关键;先在受控探针里调轨迹再进冒烟(火堆 1.3.2 的教训)
- `immersion-config.js` 挂时长/窗口参数;禁止舞台内硬编码
- smoke 断言:进入相位、时长、关键视觉事件(灯/黑屏/落水),桌面+手机双跑
